// Cada glifo empieza con una cabecera "== X" (X es el carácter, o U+XXXX en hexadecimal) y
// sigue con exactamente 13 filas. '#' es tinta y '.' es vacío. Todas las filas de un glifo
// miden lo mismo: ese es su ancho. Entre letras se deja 1 columna vacía automáticamente.
//
// Las 13 filas son las filas 3 a 15 de la celda de 16 (las filas 0 a 2 quedan para las
// tildes de las mayúsculas, que se agregan en código):
//
//   fila 0  ─ tope de mayúsculas y de las astas (b, d, h, k, l)
//   fila 1  ─ punto de la i y la j
//   fila 3  ─ tope de minúsculas (altura x)
//   fila 9  ─ última fila sobre la línea base
//   fila 10 ┐
//   fila 11 ├ descendentes (g, j, p, q, y)
//   fila 12 ┘
//
// Las letras con tilde, ñ y ü NO están aquí: se arman en código juntando la letra base
// con la marca (ver `fuente/mod.rs`), así todas las tildes quedan iguales.
